# Checks run after every commit, on the source when the commit is captured
# and on every database rebuilt from it; both must give the same answer.
#
#   q <name>|<query>     the rebuilt database answers through index <name>
#                        (the plan must use it) what the source answers
#                        with indexes off
#   s <query>            the same answer on both (sequences, views)
#   v <sqlstate>|<stmt>  the statement fails with this error on both
#
# Every index that is neither B-tree nor GIN (amcheck verifies those) must
# be used by some q check.
